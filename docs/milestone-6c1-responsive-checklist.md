## Reglas de aceptación visual

- [ ] No hay scroll horizontal global.
- [ ] Las tablas con mucha información usan scroll local o cards.
- [ ] Los botones críticos tienen área táctil suficiente.
- [ ] Los estados selected/focus/disabled son visibles.
- [ ] No se ocultan duplicados históricos de tratamientos.
- [ ] No se alteran reglas clínicas ni cálculos DDD.
