# Checklist funcional EST-03B

## Tratamiento al valorar

- [ ] Una ronda muestra solo tratamientos activos del caso seleccionado.
- [ ] Cada tratamiento permite registrar indicación y tipo Empírico/Dirigido.
- [ ] Un tratamiento nuevo exige antimicrobiano, indicación y tipo.
- [ ] “No recibe antimicrobianos” no puede coexistir con tratamientos activos o nuevos.
- [ ] Recargar el borrador conserva lo diligenciado sin duplicar tratamientos.

## Recomendación PROA

- [ ] La recomendación se distingue visualmente del tratamiento recibido.
- [ ] Están disponibles Continuar, Ajustar, Suspender, Sustituir e Iniciar tratamiento.
- [ ] Sustituir/Iniciar exige seleccionar el antimicrobiano recomendado.
- [ ] Los tratamientos evaluados permanecen vinculados a la intervención.

## Decisión e implementación

- [ ] La ronda puede guardarse con decisión Pendiente.
- [ ] Se registran Aceptada, Parcialmente aceptada y Rechazada.
- [ ] La ronda puede guardarse con implementación Pendiente de verificación.
- [ ] Se registran Implementación parcial, Implementada y No implementada.
- [ ] Se puede registrar fecha y observación de implementación.
- [ ] Una ronda posterior muestra recomendaciones pendientes y resuelve la intervención original.
- [ ] Confirmar o recargar no duplica la intervención.

## Historia y seguridad

- [ ] El expediente ordena tratamientos, recomendaciones, decisiones e implementaciones cronológicamente.
- [ ] Las rondas confirmadas no permiten editar la trazabilidad histórica.
- [ ] Cambiar de IPS limpia el contexto clínico anterior.
- [ ] Usuario INFECTOMAG solo escribe en IPS asignadas.
- [ ] IPS Cliente puede consultar, pero no escribir.
- [ ] Vista móvil conserva controles, errores contextuales y acciones sticky.
